# ✈️ Airway Reservation System

A full-stack flight booking system built with HTML, CSS, PHP, and MySQL.

## 🔧 Features
- User Registration/Login
- Flight Search & Booking
- Admin Panel (view bookings, manage flights)
- Session handling and basic validation

## 🛠️ Tech Stack
- HTML, CSS, PHP, MySQL
- XAMPP (Local Hosting)
